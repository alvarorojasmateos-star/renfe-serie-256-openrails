# RENFE Serie 256 - Modelo 3D exterior base

Este modelo es una base low-poly para un tren RENFE Serie 256 en Open Rails.
Es un bloque exterior funcional, simplificado y listo para ser refinado en Blender o cualquier editor 3D.

## Archivos
- `serie256_body.obj`: geometría principal del tren
- `serie256_body.mtl`: materiales

## Ajustes recomendados
- Importar en Blender o 3ds Max
- Escalar a metros reales si es necesario
- Añadir detalles: faros, ventanas, molduras, pantógrafo, bogies, etc.
- Exportar al formato requerido por Open Rails

## Notas
Este es un modelo base para empezar; no sustituye un modelo completo de producción de alta fidelidad.
